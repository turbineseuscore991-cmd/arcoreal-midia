# Mídia do @arcorealoficial

Artes dos posts, servidas para a API da Meta baixar na hora de publicar.

Público porque a Meta precisa alcançar as imagens pela internet — e elas vão
para o Instagram de qualquer forma. O código e as credenciais ficam no
repositório privado `arcoreal-bot`.

**Nada aqui é comprimido nem redimensionado.** Os arquivos são servidos byte
por byte como foram gerados.
